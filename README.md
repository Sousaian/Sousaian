## Projetos em destaque

### [WPP AI Bot](https://github.com/Sousaian/wpp-ai-bot-showcase)

Produto B2B proprietário em desenvolvimento para atendimento via WhatsApp, com implantação por cliente. Integra respostas com IA, contexto por prompt e histórico de conversa, além de encaminhamento para atendimento humano pelo Chatwoot.

**Tecnologias:** Python, FastAPI, SQLAlchemy, MySQL, OpenRouter, Evolution API, Chatwoot e Docker. O link apresenta o case público; o código comercial é privado.

### [Bot Telegram de Promoções](https://github.com/Sousaian/bot-telegram-promo-es)

Automação para curadoria e publicação de ofertas no Telegram, com agendamento, seleção por LLM ou heurística, deduplicação, API HTTP e modo de simulação. As integrações com lojas têm limitações de acesso e coleta documentadas.

**Tecnologias:** TypeScript, Node.js, Telegraf e Express.

### [Análise de Qualidade de Dados](https://github.com/Sousaian/analise_qualidade_de_dados)

Análise exploratória de despesas do Ministério da Saúde de dezembro de 2023, com preparação dos dados, estatística descritiva, visualizações, investigação de outliers e correlações. Discute as limitações da base para uso em modelos de IA.

**Tecnologias:** Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy e Jupyter.

### [BrasilSemLixo](https://github.com/Sousaian/BrasilSemLixo)

Protótipo educativo desenvolvido em equipe, com monitor de coleta de resíduos, seleção de bairro e rua e filtros por tipo de coleta. Utiliza dados fictícios locais, sem integração com serviços municipais.

**Tecnologias:** HTML, CSS e JavaScript. [Demonstração](https://sousaian.github.io/BrasilSemLixo/).

### Secretária Virtual Quokk

Assistente virtual para atendimento comercial pelo WhatsApp, com coleta de solicitações, confirmação dos dados com o cliente e organização das demandas para acompanhamento pela equipe.
